# Vibe Coding Skills: lesson panel for the Claude app

Learn Claude Code by building fun projects, right inside the Claude desktop app. This plugin shows
the lesson in a panel next to the chat and checks each step when Claude finishes answering.
Course and guide: [vibecodingskills.io](https://www.vibecodingskills.io).

## Install (once)

In the Claude desktop app, **Code** tab, paste each line into the message box and press Enter:

```text
/plugin marketplace add juliengibertpro/vibecodingskills-plugin
```

```text
/plugin install vibe-coding-skills@vibecodingskills
```

Then start a new session in an empty project folder and type `/atelier`.

## Privacy

The plugin reads the files of your project folder to check each step, and keeps your progress on
your computer. It never sends the text of your prompts or the content of your files anywhere.
